# amlsync.com website

Static site served from Hostinger (Single Web Hosting, `public_html`). This folder is
the source of truth: edit here, then upload the changed files with
`scripts/website-upload.sh <file…>` (Hostinger API, TUS upload; needs the Hostinger API
token configured for the session's network proxy).

The first commit of this folder is an exact backup of the live site taken on 2026-11-18.
